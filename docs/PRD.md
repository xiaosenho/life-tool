# PRD：移动端生活管理工具

## 1. 产品目标

构建一个手机端优先的生活管理工具，帮助用户完成日常专注、习惯、饮食、记账和重要事件记录，并通过服务器同步实现多设备使用、好友汇总数据查看和轻量对比。

产品重点不是做公开社交平台，而是让好友之间形成低压力的陪伴感。

## 2. 目标用户

- 希望改善时间管理、习惯执行和生活记录的人。
- 希望和朋友一起坚持目标的人。
- 希望个人数据能跨设备保存的人。

## 3. MVP 范围

第一阶段必须完成：

1. 用户注册、登录、退出登录。
2. 手机端底部导航。
3. 今日页：展示今日专注和习惯完成情况。
4. 专注计时：番茄钟、自定义倒计时、正计时。
5. 习惯管理：创建习惯、编辑习惯、每日打卡。
6. 本地 SQLite：断网可用。
7. 服务端同步：联网后上传和拉取数据。
8. 好友系统：搜索用户、申请好友、通过申请、删除好友。
9. 排行榜：今日/本周专注时长、习惯完成率、连续打卡天数。
10. 隐私设置：仅自己可见、好友仅看汇总、好友可看详情。

## 4. 第二阶段范围

1. 饮食记录和热量计算。
2. 记账记录和月度预算。
3. 重要事件记录。
4. 好友挑战。
5. 周报和月报。
6. 数据导出。

## 5. 页面结构

移动端底部导航：

```text
Today       今日总览
Focus       专注计时
Records     饮食、记账、事件
Friends     好友、排行榜、挑战
Profile     账号、隐私、同步状态
```

## 6. 隐私默认值

| 数据类型 | 默认可见性 | 好友侧展示 |
| --- | --- | --- |
| 专注记录 | 好友仅汇总 | 分钟数、排名、趋势 |
| 习惯打卡 | 好友仅汇总 | 完成率、连续天数 |
| 饮食记录 | 私密 | 默认不展示 |
| 记账记录 | 私密 | 默认不展示 |
| 重要事件 | 私密 | 默认不展示 |

## 7. 验收标准

- 用户可以注册登录。
- 用户可以离线完成一次专注计时。
- 用户可以离线完成一次习惯打卡。
- 联网后数据能同步到服务器。
- 退出登录后重新登录可以恢复数据。
- 两个用户可以互加好友。
- 好友页能看到排行榜汇总。
- 好友不能访问默认私密的原始饮食、记账和事件数据。
