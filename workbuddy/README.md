# WorkBuddy 协作目录

该目录用于给 WorkBuddy 拆分和指派独立开发任务，不存放应用运行代码。

目录约定：

- `tasks/<编号>-<任务名>/TASK.md`：目标、范围、设计约束和验收标准。
- `tasks/<编号>-<任务名>/PROMPT.md`：可直接发送给 WorkBuddy 的执行提示词。
- WorkBuddy 完成任务后，应在对应目录新增 `RESULT.md`，记录修改文件、验证结果和遗留风险。

执行规则：

1. 开始前阅读任务目录中的全部文件。
2. 保留工作区内与当前任务无关的现有修改。
3. 不扩大任务范围，不顺手重构无关模块。
4. 修改后运行任务说明中要求的验证命令。
5. 未达到验收标准时不得仅以“代码已完成”结束任务。
